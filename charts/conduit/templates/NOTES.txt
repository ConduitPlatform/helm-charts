Conduit is deployed.

Admin UI (default login admin / admin):
  kubectl port-forward svc/{{ include "conduit-helm.admin.fullname" . }} 8000:{{ .Values.admin.service.http_port }}

Redis: set redis.enabled or externalRedis.host (and password / existingSecret as needed).
Database: set mongodb.enabled or externalDatabase.url + type.
Loki: loki.setup or externalLoki.url. Prometheus: prometheus.setup or externalPrometheus.url.

install.embeddings.enabled deploys the embeddings workload only. Requires global.secret.grpc_enable.
